# Phase 2 Action Presentation Rule

This rule is intentionally small and testable:

- all four permanent lenses remain visible;
- all four permanent lenses remain selectable;
- each lens renders exactly four action labels;
- an action that cannot be used is gray/disabled;
- only that action is gray/disabled;
- its normal function label remains visible;
- no additional participant-facing unavailable/coming-soon/status explanation is required or desired;
- a disabled action has no usable navigation, trigger, command, or mutation;
- direct protected routes remain independently server-authorized.
