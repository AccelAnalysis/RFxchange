# Phase 2 Critical Path

Phase 2 exists to make the Exchange's value architecture visible before every function is complete.

Critical sequence:

```text
Phase 2 activation
→ Lane 01 current-main controller/registry implementation
→ exact-head CI/evidence
→ Control Room Elevated merge/release decision
→ canonical App Hosting rollout
→ production Room/lens/action health check
→ continue Market-Ready Baseline through Founding Membership live payment
```

Phase 2 is not a domain completion program. Domain lanes attach real handlers incrementally after the shared registry contract is stable.
