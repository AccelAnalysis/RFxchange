## Current dependency stops

- Capabilities donor work cannot enter runtime before PR #234 is reconciled.
- Intelligence donor work cannot enter runtime before PR #235 is reconciled.
- RFx Task Canvas work cannot enter runtime before the active RFx Slice 4.7–4.10 chain establishes the destination commands/workspaces.
- Provider seed/geocode data cannot write production until the private Firestore import model, Admin authority and dry-run/emulator evidence are implemented.
- Media UX cannot expose public objects until a reviewed public-media projection exists over the private INF-008 source-object boundary.

## Explicitly retired mappings

- TestRFx PostgreSQL/Neon/PostGIS remains a logical reference, not RFxchange production persistence.
- TestRFx custom sessions/HMAC verification are superseded by Firebase Authentication and RFxchange server sessions.
- MapLibre/OpenFreeMap implementation code is retired; desired behaviors must be reauthored for Mapbox.
- Static Pages preview is not a production success path or data/identity authority.

## Change control

A mapping change requires updating the JSON ledger, affected feature rows, this summary, the admission gate if needed, and the validator test.
