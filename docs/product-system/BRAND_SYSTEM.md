# RFxchange Brand System

## Identity

Primary wordmark: **RF** in RF Gold and **xchange** in Exchange Black on light backgrounds or white on dark backgrounds. Use `™` unless counsel authorizes registered-mark usage.

The compact `RF` monogram is the app/fav icon primitive.

## Color

| Token | Hex | Purpose |
| --- | --- | --- |
| Exchange Black | `#0B0B0D` | depth, primary structure |
| RF Gold | `#D6A23A` | attention, primary network signal |
| Warm Ivory | `#F7F3EA` | light canvas |
| Graphite | `#252932` | panels, secondary structure, type |
| Signal Blue | `#2E5EAA` | intelligence, data, links |
| Growth Green | `#3B7B57` | outcomes, progress |

Target usage: 70% canvas, 20% black/graphite structure, 7% gold, 3% blue/green data signals. This is a design discipline, not a pixel-count acceptance test.

## Typography

Display: Aptos Display with Aptos/Segoe UI/Helvetica/Arial fallbacks.
Body and data: Aptos with Segoe UI/Helvetica/Arial fallbacks.

Use typography and whitespace before adding containers or dividers.

## Visual language

- Geography is the organizing field once real GIS is available.
- Gold paths represent purposeful connection: opportunity, referral, support, or outcome flow.
- Blue is intelligence; green is growth/outcome.
- Use realistic journey language and measured data.
- Pins must ultimately be anchored to real coordinates; locality emphasis must come from geographic layers, not floating DOM decoration.

Wave 0 intentionally does not implement fake GIS to satisfy a brand checkbox.
