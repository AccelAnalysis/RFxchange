# Presentation System

## Shared narrative spine

1. Fragmented local economy
2. Why fragmentation costs growth
3. The RFxchange solution
4. Complete business journey
5. Trust and data boundaries
6. Audience-specific value
7. Pilot / launch pathway
8. Participation request

## Audience emphasis

### Economic developers and civic leaders
Connective economic infrastructure: visibility, coordination, intelligence, measurable pilot outcomes.

### Founding businesses
Reusable business-development position: be found, find demand, build capacity, act with context.

### Resource providers
Contextual resource and referral layer: qualified routing, service territories, capacity-aware handoffs.

## Slide compositions

### Hero
One short claim + one focal map/network visual + one audience implication.

### Journey
One 5–7-stage pathway. Make the business movement visible; avoid a feature grid.

### Evidence
One statistic or evidence point + sober implication + source/caveat.

### CTA
One specific participation request + next action.

## Composition rule

Each slide gets one headline, one focal visual, one action logic, and one audience implication. Prefer whitespace and hierarchy over containers, decorative borders, or dashboard-like density.
