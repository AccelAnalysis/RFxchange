# Hampton Roads Provider Promotion Review

**Status:** Implemented — Not Verified

**Production authority:** `AccelAnalysis/RFxchange`

**Stacked over:** Protected Hampton Roads provider Firebase promotion

**Effective:** 2026-08-24

## Purpose

This packet converts the PR #243 source migration plan and accepted-location Geography Fabric enrichment into a deterministic administrative review queue. It resolves a sequencing problem that must remain explicit:

> Canonical Organization search must happen before RFxchange knows whether the provider will create a new Organization or attach to an existing one, while the final Location Geography Profile must be bound to the Organization actually selected.

The packet therefore keeps source/geography review evidence target-neutral until an administrator records a create-versus-attach comparison outcome.

## Review sequence

```text
PR #243 migration plan
        +
accepted-location Geography Fabric enrichment
        ↓
target-neutral provider review item
        ↓
current canonical Organization search
        ↓
explicit administrator comparison decision
        ↓
target Organization selected
        ↓
target-bound Location Geography Profile materialization
        ↓
promotion candidate + canonical comparison evidence
        ↓
separate approval packet
        ↓
protected Firebase preview / commit
```

No approval or production write is inferred by this packet.

## Review queue

Every source candidate is retained in exactly one queue state:

- `ready-for-canonical-search` — accepted coordinate and complete Geography Fabric resolution; ordinary canonical search may proceed;
- `identity-review-required` — accepted coordinate and geography are present, but classification or canonical identity requires the dedicated review path;
- `needs-geography-resolution` — accepted source location exists but Geography Fabric resolution is incomplete;
- `blocked` — held out, unresolved, or otherwise not eligible for promotion review.

Each item remains `promotionEligible: false`. A source record appearing in the review queue is not approval.

## Evidence binding

The review manifest records deterministic fingerprints for:

- the stable PR #243 migration-plan evidence, excluding volatile generation time;
- the Geography Fabric enrichment manifest;
- each normalized source-backed provider record;
- each target-neutral accepted-point geography resolution.

The source record and geography resolution must retain the same accepted-point fingerprint. Any change to the accepted coordinate, source identity, or resolved geography invalidates compilation.

## Target-neutral geography

The review queue stores accepted-point resolution evidence—not an Organization-bound Location Geography Profile.

This is intentional. Before canonical search, RFxchange cannot truthfully know whether the provider belongs to:

- a new unclaimed canonical Organization; or
- an existing reviewed canonical Organization.

After the administrator selects the target, the comparison compiler materializes the Geography Profile using that exact Organization and deterministic source-backed Location ID. The resulting profile fingerprint then binds the final promotion candidate and comparison evidence.

## Canonical comparison

Only ordinary `ready-for-canonical-search` items may enter the comparison compiler.

For a new Organization:

- the target Organization ID is explicitly reserved;
- no existing Organization is selected;
- current search evidence is retained;
- the target-specific Geography Profile is materialized;
- comparison evidence states `create-new-organization`.

For an existing Organization:

- the target must appear in the current canonical search snapshot;
- the selected match evidence is retained;
- the target-specific Geography Profile is materialized for that Organization;
- comparison evidence states `attach-to-existing-organization`.

Identity-review and blocked records cannot use this ordinary path.

## Offline script

`prepare-hampton-roads-provider-promotion-review.mjs` requires an explicit Geography Fabric enrichment manifest generated by the preceding resolver packet. It writes only an offline JSON artifact and reports:

- source candidate count;
- canonical-search-ready count;
- identity-review count;
- geography-resolution count;
- blocked count;
- `productionWrites: false`;
- `approvalsInferred: false`.

The script contains no Firebase Admin, Firestore, PostgreSQL, PostGIS, or alternate-runtime write path.

## Packet boundaries

This packet does not:

- query production canonical Organizations offline;
- fabricate canonical search results;
- decide create versus attach automatically;
- resolve identity-review records through the ordinary path;
- create an approval;
- stage evidence into production Firestore;
- execute preview or commit commands;
- publish provider discovery or a Resource;
- activate a map marker.

The next controlled operation is to run the offline enrichment/review artifacts, perform current canonical searches, record explicit administrator comparison and approval decisions, and then use PR #251's protected preview/commit adapter for only those approved records.
