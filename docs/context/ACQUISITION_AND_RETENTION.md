# RFxchange Acquisition & Retention Context

## Growth model

RFxchange should acquire participants through useful economic objects and relationships, not primarily through a generic SaaS funnel.

Core flywheels:

```text
Seed → Reach → Acquire → Activate → Deliver Value → Build Habit → Convert → Retain → Expand → Advocate
```

and

```text
More Organizations → More Capabilities → More Opportunities → More Connections → More Outcomes → Better Intelligence → More Value → More Organizations
```

## Market the object, not merely the platform

High-intent acquisition begins with something the participant already wants, such as:
- an opportunity,
- an organization profile waiting to be claimed,
- a referral,
- a team invitation,
- a buyer/supplier need,
- a relevant provider/resource,
- a locality/network launch.

## Public opportunity entry

A visitor should be able to understand enough of a permitted public RFx/opportunity to become interested before registration. The CTA should preserve the object intent (for example **View Opportunity**) rather than forcing a generic join funnel.

## Preserve entry context

Registration must preserve why the person arrived. Supported entry contexts include opportunity, organization claim, referral, team invitation, provider recommendation, buyer need and other approved acquisition objects.

After authentication/onboarding, return the user to the relevant object or next action rather than an empty generic dashboard.

## Seed-and-claim

A seeded organization profile can function as an acquisition surface. Show appropriate public organization/location/category data, clearly label the profile as unclaimed, and allow **Claim this organization**.

The user is taking control of an organization presence, not creating an unattached personal account.

## Institutional distribution

EDOs, chambers, governments, APEX/SBDC/workforce/university partners and other approved institutions can recruit businesses and providers into a locality/network. Partner attribution must not imply that an institution owns the network or gains unauthorized access to participant data.

## Referrals and teaming as acquisition

An external organization invited to receive a referral or discuss a team opportunity should register into that context. These are high-intent routes and should not discard the invitation after signup.

## Resource acquisition loop

Resource providers may share relevant opportunities or profile-completion paths, while businesses discover providers in context. Optimize for qualified routing and relevant service territory/eligibility rather than lead volume.

## Activation target

The activation objective is not merely registration. A successful organization should establish a legitimate organization presence and reach the real controlled-map environment quickly.

## First value

Use stated objectives and preserved acquisition context to drive the first useful action. Examples include saving/pursuing an opportunity, finding a teammate, receiving a referral, finding a provider, becoming discoverable or issuing demand.

## Retention

Retention should come from recurring economic usefulness: saved searches/alerts, opportunity changes, referral status, team activity, provider follow-up, issuer workflows, profile visibility and relevant intelligence.

Relevance is more important than notification volume.

## Conversion

Upgrade prompts should be contextual to demonstrated value, limits or advanced workflow needs. Do not interrupt minimum registration with premature commercial conversion.
