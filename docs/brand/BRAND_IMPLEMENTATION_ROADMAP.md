This roadmap sequences the premium Brand Experience System without destabilizing completed behavior or fabricating later-wave domains.

Brand convergence uses small, reviewable gates. Each gate must preserve:

- authorization and organization isolation;
- activation and OPEN lifecycle authority;
- authoritative geography and privacy-safe coordinates;
- marker visibility and renderer ownership;
- acquisition-context integrity;
- synthetic/live isolation;
- RFx, referral, provider, credibility, and commercial boundaries;
- tracker and Feature-ID discipline;
- responsive, accessibility, recovery, and performance requirements.

## 8. Branch and merge discipline

For every remaining gate or product slice:

- branch from current merged `main`;
- implement one authorized scope;
- preserve security, lifecycle, geography, privacy, and domain authority;
- run repository and applicable configured-browser acceptance;
- keep the PR draft until required evidence exists;
- merge before recalculating the next boundary;
- do not mark Feature IDs complete from visual convergence;
- do not use visual simulation as evidence of a domain feature.
