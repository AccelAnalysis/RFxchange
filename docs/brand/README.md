> **A local market becoming visible and useful around every participating organization.**

## Authority model

After the current task, security/domain, tracker/dependency, and authorized-slice/gate authority:

- `docs/brand/` defines the approved target experience and acceptance;
- `docs/design/` defines the implemented/converged design baseline;
- runtime is implementation evidence and compatibility context.

A brand rule never grants domain authority, creates a Feature-ID completion claim, or permits a future visual object to appear as live without its authoritative source domain.
