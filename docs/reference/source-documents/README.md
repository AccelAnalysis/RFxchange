## Raw-source storage policy

When raw source files are committed to this directory, preserve the original filename or a clearly mapped archival filename and do not edit the raw copy to match later implementation. Product decisions should be updated in `docs/context/`, tracker/dependency authority or an approved architecture/slice document while the raw source remains provenance.
